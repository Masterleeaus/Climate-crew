# Legacy assets

Historical images, audit reports, and the retail model binaries were removed from the current source tree. The `legacy-assets-v1.0.0` release bundle recovers them from the pre-cleanup repository snapshot after the release workflow runs. Their upstream origin and license are not documented in repository history. These files are retained for traceability only and are not used by the default Climate Crew application. See [`PROVENANCE.md`](../../PROVENANCE.md) and [`docs/release-assets.md`](../../docs/release-assets.md).
