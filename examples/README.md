# Archived experiments

These directories preserve non-core experiments removed from the default Climate Crew API and frontend.

- `retail_analytics/` — former retail audit, causal-analysis, dataset and UI experiment; model binaries will be in the archived asset release.
- `climate_finance/` — former market-impact, ESG, climate-finance API and UI experiment.
- `legacy_assets/` — README for the historical images, generated audit reports and feature document, which the release workflow packages.

The source experiments remain in `examples/` for traceability and are not mounted by `main.py` or the current frontend. They may depend on provider credentials and the former application package layout; they are not maintained as standalone packages. Their presence is not evidence that those features are part of the current Climate Crew science workflow.
