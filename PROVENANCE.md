# Provenance and attribution

## Climate Crew source lineage

The public repository history contains commit `e2691313d9bd8dfdf3f07a3cc2cbaa0922f79b0a`, titled **“Unpack ClimateX source into repository”**, dated 2026-09-26. The prior workflow `.github/workflows/unpack-climatex.yml` extracted `ClimateX.ai-main.zip`, replaced matching repository paths, and pushed the result to `main`. That workflow is removed in this branch because it granted write access and could overwrite current files.

The archive is not present in the current default-branch tree. The commit history does not record an upstream repository URL, original author, or source license. This document therefore records ClimateX as the codebase's predecessor but does not claim the contents came from a specific external project. The old audit agent, route identifiers, PDF footer and some comments still use ClimateX branding; those names are historical code identifiers, not an attribution claim. Historical binary assets are removed from the current source tree and can be reconstructed by the release workflow from the pre-cleanup snapshot `50dcd4dfd4aefab233a548faf400e46353291cb3`. The release itself still needs to be created from the workflow after merge.

The former retail and climate-finance/ESG modules are moved under `examples/` and removed from the default API/frontend. They are archived prototypes, not supported app modules. `LICENSE` applies MIT terms to original project contributions by Jason Lee only; it does not establish licensing for historical code whose source and authorship are unknown or supersede any third-party license. Restore any discovered upstream notices alongside the affected files before redistribution.

## NASA GISTEMP data

The reproducible analysis uses NASA GISS GISTEMP v4 global land-ocean temperature anomalies:

- Data page: <https://data.giss.nasa.gov/gistemp/data_v4.html>
- CSV: <https://data.giss.nasa.gov/gistemp/tabledata_v4/GLB.Ts%2BdSST.csv>
- Snapshot date: 2026-10-04
- Snapshot SHA-256: `c9ce0750ca93a8241c42fe86cd5bf54d07b28b21ae650b0ae49a206907018cd9`
- Analysis: annual `J-D` column, 1951–1980 reference period, complete years 1880–2025

NASA periodically revises the source data. The checked-in file is a fixed reproducibility snapshot; later source revisions should be added as a new snapshot rather than silently replacing this one.

## Test and evaluation provenance

The CI tests use local data and mocked provider responses. The 60-case evaluation dataset is synthetic and generated by `eval/science_quality/build_dataset.py`; it is not observational climate evidence. The existing application and general evaluation modules have not been fully reproduced in CI by this workflow.
